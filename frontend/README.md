# IIHS Media Archive frontend

Next.js App Router application for the IIHS Media Archive. This initial frontend is a search-first shell; archive data and search requests will connect to the Python backend in a later integration step.

## Development

```bash
npm install
npm run dev
```

The app uses React and TypeScript, Tailwind CSS 4, local shadcn-style components with Radix primitives, and the configured state, query, animation, and form libraries.
